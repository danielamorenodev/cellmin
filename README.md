# sistema-ventas
Sistema de gestión de ventas, stock y reparaciones (Cellmin)

## Desarrollo local
- Backend: `cd backend && uvicorn app.main:app --reload` (necesita `backend/.env`, ver `backend/.env.example`)
- Frontend: `cd frontend && npm run dev`
